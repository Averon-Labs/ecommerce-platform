# .ai/plans/ — Implementation Plans

## Purpose

This directory contains implementation plans created by agents before starting complex tasks.

## Naming Convention

```
<TASK-ID>.md
```

## Template

```markdown
# Plan: <TASK-ID> — <Title>

## Approach
- ...

## Files to Create/Modify
- ...

## Steps
1. ...
2. ...

## Testing Plan
- ...

## Risks
- ...
```

## Guidelines

- Create a plan file only for substantial persistent context that cannot fit in the roadmap entry; otherwise keep the plan in the task discussion (rule from `AGENTS.md`).
- Keep plans concise and actionable.
- Update or remove plans as tasks are completed.
