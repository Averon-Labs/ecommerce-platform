## 🎯 Quick Routing Protocol for AI Agents

1. **If user request involves Android, Java, XML, or Material 3**:
   👉 Route directly to `android/SKILL.md`. Enforce 48dp touch targets, flat `ConstraintLayout` with `Flow`, M3 tonal color tokens, and Edge-to-Edge insets.
2. **If user request involves Web, React, Next.js, Tailwind, or shadcn/ui**:
   👉 Route directly to `web/SKILL.md`. Enforce zero CLS, visible focus rings, Compound Component patterns, and Bento grid / Glassmorphic visual craft.
3. **If user request requires both or general design direction**:
   👉 Use the shared principles: **Dribbble visual craft + strict engineering guardrails (WCAG 2.2 AA, 4.5:1 contrast, and zero layout shift)**.
