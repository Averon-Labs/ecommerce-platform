# اسکیل جامع UI/UX برای اندروید و وب (My UI/UX Skill)

این مجموعه اسکیل، حاصل ادغام و عصاره‌گیری از ۴ پروژه بزرگ دیزاین سیستم ایجنتیک دنیاست:
1. **`material-3-skill`** (دیزاین سیستم رسمی گوگل)
2. **`ui-ux-pro-max-skill`** (استایل‌های ترند Dribbble و پالت‌های مدرن)
3. **`VERCELL-agent-skills`** (استانداردهای طلایی مهندسی فرانت‌اند و معماری کامپوننت)
4. **`all-skills / frontend-design`** (اصول تایپوگرافی اصیل و مبارزه با طرح‌های تکراری و بی‌کیفیت هوش مصنوعی)

---

## ساختار پکیج:

### ۱. اسکیل تخصصی اندروید (`android/`)
* **هدف:** توسعه‌دهندگان Android با **Java** و **XML Layouts**.
* **زیبایی‌شناسی:** کارت‌های Bento Grid مدرن، افکت‌های شیشه‌ای (Glassmorphism)، نوار ناوبری شناور و گرادیان‌های محو.
* **مهندسی و UX:**
  * رعایت کامل ۲۹ نقش رنگی Material Design 3 (Material You).
  * پشتیبانی کامل از Android 15 Edge-to-Edge و هندلینگ Insets کیبورد و استاتوس‌بار.
  * الزام به حداقل ابعاد لمسی ۴۸×۴۸dp طبق WCAG 2.2.
  * جلوگیری از افت فریم و لگ با حذف لایه‌های تودرتو و استفاده از `ConstraintLayout Flow`.
  * انیمیشن‌های فیزیکی ارتجاعی (`SpringAnimation`) در جاوا.
* **فایل‌های آماده:** دارای تمپلیت‌های آماده `colors.xml`، `dimens.xml`، `type.xml` و شیپ‌های وکتور `drawables/`.

---

### ۲. اسکیل تخصصی وب (`web/`)
* **هدف:** توسعه‌دهندگان Web با **React**، **Tailwind CSS** و **shadcn/ui**.
* **زیبایی‌شناسی:** طراحی بنتو گرید نامتقارن، دارک‌مود عمیق OLED (بدون خاکستری‌های کدر)، لبه‌های کریستالی با بوردر ۱ پیکسلی، و حذف المان‌های تکراری هوش مصنوعی (Anti-AI Slop).
* **مهندسی و UX:**
  * حذف کامل پرش چیدمان (Zero CLS با ابعاد رزرو شده و اسکلتون هم‌اندازه).
  * رعایت حلقه‌های فوکوس کیبورد (`focus-visible`) بدون حذف outline.
  * اعداد تبولار (`tabular-nums`) برای عدم لرزش قیمت‌ها، تایمرها و جداول.
  * معماری کامپوننت ترکیبی (Compound Components) با فرمت سه‌گانه `{ state, actions, meta }`.
  * انیمیشن‌های روان ۶۰ فریم بر ثانیه با View Transitions بومی مرورگر.
* **کامپوننت‌های آماده:** دارای کامپوننت‌های آماده تایپ‌اسکریپت `BentoGrid.tsx`، `GlassCard.tsx`، `FloatingNav.tsx` و `CompoundModal.tsx` به همراه تنظیمات `tailwind.config.ts` و متغیرهای `globals.css`.

---

## نحوه استفاده توسط هوش مصنوعی (Agent):
تنها کافی است این فولدر را به عنوان اسکیل در محیط‌های ایجنتیک خود (مثل Antigravity، Claude Code، Cursor و ...) معرفی کنید. فایل ریشه `SKILL.md` به صورت خودکار درخواست کاربر را تشخیص داده و به اسکیل اندروید یا وب هدایت می‌کند.
